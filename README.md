# WhatsApp Business Manager (Python + Flask + Meta API)

A simple WhatsApp Business management system using Python, Flask, SQLite, and WhatsApp Cloud API (Meta).

This project is designed for learning and building a CRM-style system for managing contacts, logs, and WhatsApp webhook events.

---

## 🚀 Features

- Add & manage contacts
- Store message logs
- WhatsApp webhook receiver (Meta Cloud API)
- Message delivery status tracking (ready structure)
- SQLite database support
- Termux compatible
